# Smart Security - Tkinter applicatie

Een eenvoudige desktopprototype van een Smart Security-inlogscherm, gebouwd met
Python en Tkinter. De applicatie toont een titel, een invoerveld en een
inlogknop.

## Vereisten

- Python 3
- Tkinter (meegeleverd met de meeste Python-installaties)

## Starten

Open een terminal in de projectmap en voer uit:

```bash
python main.py
```

Op sommige systemen is het commando:

```bash
python3 main.py
```

## Gebruik

Na het starten verschijnt een venster met:

- de titel **SMART SECURITY**;
- een invoerveld voor gegevens;
- een knop **Log in**.

De knop is op dit moment alleen een visueel onderdeel van het prototype en
voert nog geen authenticatie uit.
